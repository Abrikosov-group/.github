# Правила для ИИ-агентов

## Code Review Rules

### Язык ревью

- Публикуй итог ревью, резюме, заголовки и все инлайн-комментарии только на
  русском языке.
- Идентификаторы, пути, команды, названия API и библиотек, сообщения об ошибках
  и фрагменты кода оставляй в исходном виде.

## Общие группы раннеров

- При добавлении workflow в существующую организационную группу раннеров
  используй `scripts/runner-group-workflows.mjs` по `scripts/README.md`.
  Не отправляй прямой `PATCH` группы без сохранения и проверки полного списка
  допущенных репозиториев.
